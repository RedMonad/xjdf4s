# M1.5 — Тестовая инфраструктура и coverage

Статус: `[~]` переоткрыта (P2/P3 по результатам аудита)

Цель: law-suite полон, fixtures воспроизводят нормативные примеры, coverage
измеряет фактическое соответствие.

## Задачи

### M1.5-1. Исчерпывающий реестр instances/rules/enums (P2)
Находка: ручные реестры неполны; тесты «Monoid unattainable», «Patch
associativity», fromToken/duplicate покрывают подмножество.
Решение: один source manifest перечисляет все public algebra instances,
DomainRules и closed enums. Для каждого instance — полный шаблон законов;
для отсутствия Monoid/Group — compile-time negative test. Автоматически
регистрировать все `XjdfEnum`.

### M1.5-2. Машинная сверка enum на главы 4/6/7/8 (P3)
Находка: машинная перекрёстная проверка enum покрывает только Appendix A;
закрытые enum глав 4/6/7/8 проверяются только рукописными golden.
Решение: расширить механизм `EnumLaws` на inline enum глав 4/6/7/8.

### M1.5-3. Conformance fixtures: verbatim spec examples (P1)
Находка: golden-тесты проверяют `Show`, который теряет почти всё содержимое
тикета; fixtures не воспроизводят нормативные примеры дословно; часть ссылок
на примеры несуществует.
Решение: хранить verbatim XML/JSON блоки нормативных примеров; до M2 сравнивать
извлечённую domain projection со списком обязательных traits, в M2 —
decode/encode golden. Удалить ссылки на несуществующие примеры.

### M1.5-4. Coverage checker: field-level (P3)
Находка: checker проверяет наличие имени типа, не поля/правила; строки
`Implemented`/`Validation ✅` завышены.
Решение: генерировать manifest table→attributes/children/types/cardinalities
из XSD и prose; сравнивать с declarative model metadata. Статусы:
Complete / Partial(n/m) / Planned / Codec-only.

### M1.5-5. Dependency report по sbt-модулям (P3)
Находка: отчёт сворачивает всё в один модуль `modules`; не проверяет
`core ↛ laws/examples`; не включает test scope.
Решение: узлы маркировать `core/laws/examples`; включить test sources;
дать две матрицы: compile module graph и file graph.

## Definition of Done M1.5
- Law-suite полон; законы проверяются относительно точного Eq.
- Conformance fixtures воспроизводят нормативные примеры.
- Coverage отражает фактическое, а не заявленное соответствие.
