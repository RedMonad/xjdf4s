# M1.4 — Архитектура, алгебры и безопасный API

Статус: `[~]` переоткрыта (P2 по результатам аудита)

Цель: ацикличность, безопасные конструкторы, законные алгебры.

## Задачи

### M1.4-1. Foreign extension как qualified name (P1)
Находка: `Extension(namespace="foo", local="FooIntent").elementName` возвращает
только `FooIntent`, но нормативный `Intent/@Name` равен `foo:FooIntent`.
Локальные законы сравнивают строки напрямую и отвергают extension.
Решение: ввести `QualifiedName(prefix, local)` с canonical token; использовать
в ResourceSetName/IntentName и extension payload; сравнивать qualified names.

### M1.4-2. Закрыть фабричные обходы opaque-инвариантов (P2)
Находка: `IssueCode.apply`, `NsPrefix.unsafe`, `CommentText.apply`, numeric
`apply`, `Severity.fromScore` обходят валидацию; `PartAmount`/`AmountBounds`
бросают `require`.
Решение: сделать unchecked constructors private/package-private; оставить
`from`/`unsafe` с общей проверкой; `Severity.fromScore` вернуть Option/Either;
raw case class constructors скрыть, заменить smart constructors.

### M1.4-3. XPath-локаторы коллекций: 1-based (P2)
Находка: `zipWithIndex` вставляется как `[0]`, `[1]`; XPath позиционен с 1.
Решение: общий helper `childPath(name, zeroBasedIndex)` рендерит `[index0+1]`;
эскапировать literal predicates.

### M1.4-4. Разделить payload dispatch и validation traversal (P2)
Находка: `AllResources`/`AllIntents` — bottleneck; каждый payload требует
синхронной правки центральных match/validator узлов.
Решение: payload сам предоставляет elementName/refs/ids/local issues через
небольшой typeclass/registry; TicketValidator агрегирует, а не pattern-match
всех case. Делать до массового M3.

### M1.4-5. Удалить незаконные floating algebra instances (P2)
Находка: `CommutativeMonoid[XYPair]`, `CommutativeMonoid[Points]`,
`Monoid[Matrix]`, `Semigroup[Amount]` над `Double` не lawful относительно
точного Eq (IEEE-754 не ассоциативен). NaN ломает Eq reflexivity и
Order consistency.
Решение: удалить cats-инстансы с raw Double carriers либо заменить на exact
decimal/rational/quantized representation; приблизительные операции — обычные
именованные методы. Запретить NaN/Infinity там, где объявлены Eq/Order.

## Definition of Done M1.4
- Циклов файловых зависимостей 0.
- Safe API не бросает непомеченных исключений.
- Все объявленные cats-инстансы lawful и покрыты тестами.
