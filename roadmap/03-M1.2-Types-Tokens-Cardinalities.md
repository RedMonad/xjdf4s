# M1.2 — Типы, токены и кардинальности XJDF 2.2

Статус: `[~]` переоткрыта (ряд P1 по результатам аудита)

Цель: доменные типы точно соответствуют нормативным таблицам и XSD.

## Задачи

### M1.2-1. AuditPool: `Chain[Audit]` вместо `NonEmptyChain` (P1)
Находка: Table 3.3 задаёт детей с кардинальностью `*`, XSD —
`xs:choice minOccurs="0" maxOccurs="unbounded"`. Пустой `<AuditPool/>`
структурно допустим. Текущий `NonEmptyChain` его не представляет.
Решение (подтверждено владельцем): `AuditPool` = wrapper над `Chain[Audit]`,
добавить `empty`, заменить `Semigroup` на lawful `Monoid`, `latest`/`oldest`
возвращают `Option`. Различие «AuditPool отсутствует» vs «присутствует пустой»
сохраняется через `Option[AuditPool]`.

### M1.2-2. NamedColor: закрыть enum (P1, решение владельца — вариант B)
Находка: поля с типом `NamedColor` представлены открытым `NmToken`.
§1.10.3.1 однозначно требует закрытое множество для `enumeration` /
`Allowed value is from:`. §A.2.30 называет `[Color Names]` списком allowed values.
Решение: ввести закрытый `NamedColor` (147 значений SVG 1.1), заменить `NmToken`
во всех полях типа `enumeration, Allowed value is from: NamedColor`.
Политика canonical token / case-insensitive decode фиксируется отдельно для M2.
Migration: breaking для Color/Binding/Media и др. — полный список call sites.

### M1.2-3. XML lexical validators для ID/IDREF/NMTOKEN (P1)
Находка: `Id.from`, `IdRef.from`, `NmToken.from` принимают любую непустую строку
без whitespace, не проверяя XML Schema lexical space. Строки `"1"` для `ID`,
`"a/b"` для `NMTOKEN` проходят, но не принадлежат соответствующим типам.
Решение: реализовать корректные lexical predicates по XML Schema для `NmToken`,
`Id`, `IdRef`, `NsPrefix`; `NsPrefix` проверять как NCName и запрещать colon.
`unsafe`-конструкторы делегируют проверке.

### M1.2-4. RunList и ByteMap (P1)
Находка: `docPages` должен быть `IntegerList`, `docs`/`sets` — `IntegerRange`,
отсутствует `clipPath: PDFPath`, `ordType` должен быть закрытым enum
`Content|Insert|Reservation`. `ByteMap` смешан с `Band`, изобретает обязательные
`height`/`width`, теряет ряд полей.
Решение: исправить типы по Tables 6.148/6.150/6.151; разделить `Band` и `ByteMap`.
Prose/XSD gap по `Docs` (prose `IntegerRange`, XSD `IntegerList`) — выбрать prose
и зафиксировать явно.

### M1.2-5. Contact family (P1)
Находка: `contactTypeDetails` должен быть `NmTokens`, `userId` — `XjdfString`,
`channelUsage` — `NmTokens`; обязательные `ComChannel/@Locator` и
`Company/@OrganizationName` сделаны `Option`; у `Person` отсутствуют
`NameSuffix`, `PhoneticFirstName`, `PhoneticLastName`.
Решение: исправить типы и обязательность по Tables 6.38–6.42.

### M1.2-6. DeliveryParams (P1)
Находка: отсутствуют `Ownership`, `Transfer` и три роли `FileSpec`;
`TrackingID` должен быть `string`, не `NmToken`.
Решение: добавить закрытые Ownership/Transfer, исправить TrackingID,
представить ролевые FileSpec без потери роли (Table 6.54).

### M1.2-7. Preview (P1)
Находка: `compensation` должен быть закрытым enum `None|Film|Plate|Press`,
`previewFileType` — закрытым enum `PNG|CIP3Multiple|CIP3Single`;
отсутствует deprecated `CTM: matrix`.
Решение: ввести закрытые enum, удержать CTM как lossless (Table 6.134).

### M1.2-8. Coverage: допустить кумулятивное покрытие (P1)
Находка: `Coverage.from` ограничивает `[0,100]`, но Table 4.21 приводит
`Coverage="400"` для сплошного CMYK.
Решение: заменить на домен, допускающий неотрицательное кумулятивное покрытие
(верхняя граница — по нормативному тексту; как минимум 400 представимо).
Добавить boundary fixtures 0/100/400.

### M1.2-9. duration и language (P1)
Находка: `TimeSpan` на `java.time.Duration` не представляет календарные
`xsd:duration` (`P1M`, `P1Y`). `LanguageTag` слишком строг относительно RFC3066.
Решение: ввести lossless XSD duration ADT (months + seconds/sign); конверсию в
`java.time.Duration` сделать частичной. Language parser реализовать по RFC3066.

### M1.2-10. Intent payload опционален (P1)
Находка: Table 4.1 задаёт специфический Product Intent с кардинальностью `?`,
но `Intent.specific: IntentPayload` обязателен. Bodyless Intent непредставим.
Решение: `specific: Option[IntentPayload]`; nameLaw проверяет совпадение только
при наличии payload.

### M1.2-11. FloatList/IntegerList допускают пустой список (P1)
Находка: Appendix A говорит «list», XSD использует `xs:list` без `minLength`;
пустая лексическая форма допустима. Текущий `of(head, tail*)` требует head.
Решение: добавить `empty` / `from(List)`. Fixed-length типы (Shape/XYPair/
IntegerRange) остаются отдельными.

### M1.2-12. Generic Resource traits (P1)
Находка: отсутствуют `@CommentURL`, `@Expires`, `@StartOffset`; нет правила
`StartOffset` несовместим с `Start`.
Решение: добавить поля по Table 6.1 и DomainRule взаимного исключения.

## Definition of Done M1.2
- Все перечисленные типы/кардинальности сверены с нормативными таблицами и XSD.
- На каждое изменение — регрессионный тест.
- Расхождения prose/XSD зафиксированы явно.
